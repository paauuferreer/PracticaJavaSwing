# Practica Java Swing - Gestió de lloguer de videojocs

Pràctica de l'assignatura Desenvolupament d'Interfícies. Aplicació feta amb Java Swing per gestionar el lloguer de videojocs, usuaris i estoc en memòria local.

## Com executar el projecte

1. Obrir el projecte amb NetBeans.
2. Fer Clean and Build al projecte per descarregar dependències si fa falta.
3. Executar el projecte prement F6 o el botó Run.
